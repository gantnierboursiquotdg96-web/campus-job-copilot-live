# 实时读取与转换

来源：`assets/live-source.json` 的固定Base和校招Table；读取整表，不读取买家个人管理记录。脚本以用户身份调用CLI，单页2000条，直到has_more=false；各页rev与查询范围一致、记录ID唯一，最后再核对table-list返回的rev与总数。若读取期间变化，输出失败而非不完整推荐。只有本轮成功读取后才搜索；每轮生成独立快照目录用于追溯，不从旧快照回退。

字段通过稳定field_id定位，显示名以每页manifest为准。重命名仍能读取；删除或重建字段导致ID改变时停止，卖家需更新配置。

届别提取显式四位年份；原备注和岗位原文保留，原文冲突须人工核实。招聘批次只归一为秋招/春招/实习/补录。城市分隔拆解，保留原文；联合城市记录不表示每个岗位在所有城市均开放。角色为保守关键词分类，未命中就不分类；管理管培无法可靠细分时标为职能，不自动当成电商运营。行业从原分类拆解并归一部分常用标签，不推断企业实际JD。

日期仅接受显式完整年月日或更新时间RFC3339；不从更新时间补齐缺失年份。10.31、尽快投递、招满即止都不产生deadline_date。笔试“需要笔试”记为true；含免笔试/仅测评/混合选项保持未知，并保留原文。

链接文本只存在一个不同URL时提取该URL；重复Markdown包装清理，多URL或无URL保留原文，输出链接未知。不验证招聘网页是否仍可用。机会ID由Base/Table/record_id哈希生成，同一源记录更新时稳定；删除重建记录会获得新ID。

完整性校验只证明读取一致，不证明源招聘信息准确、仍开放或候选人具备资格。评分采用原六维算法，使用粗分类，并非任职资格或录用概率。
